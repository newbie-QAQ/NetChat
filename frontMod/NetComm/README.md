# NetComm（双端通信）— NetChat 的前置模组

本目录存放 NetComm 的**编译产物**（NetComm.dll + 配置文件），供 NetChat 安装包直接使用。

- **原作者：444**（TPML 生态模组，源码版权归原作者所有，本仓库不分发其源码）
- 本构建在原版基础上做了一处修改：发送节流从固定的每帧 8 片改为可调（`SlicesPerFrame`，1~64，NetChat 设置页可调），其余逻辑未动
- 版本：1.0.2（修改版）
