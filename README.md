# NetChat 隐秘聊天

Terraria 1.4.5.8 + tPlainModLoader (TPML) 的隐秘聊天模组：不用服务器装任何东西，聊天内容只有装了本模组的玩家互相可见，服务器和旁观玩家完全看不到。

## 功能

- **隐秘聊天 / 表情 / 私聊** — 聊天室窗口独立于原版聊天，进出房间有提示、未读角标、消息提示音
- **头像** — 设置页选图，200×200 显示在消息旁
- **图片互发** — 选图发送，进度条可视化，支持取消和发送队列（最多排 5 张），接收图存到「文档\My Games\Terraria\NetChat\recv」
- **辅助** — 消息右键复制、每帧发送片数可调（1~64）、状态栏排障
- **自动更新分发** — 和作者在同一个服务器里，作者会自动把新版本传给你（RSA 签名验证，杜绝恶意推送）

## 安装

1. 需要 [tPlainModLoader](https://github.com/)（TPML，原版模组启动器）
2. 把发布包里的 `NetChat` 文件夹整个放进游戏目录的 `Mods/` 下
3. 进游戏，聊天框左侧的开关图标亮起即生效

详细玩法见 [使用说明.md](使用说明.md)。

## 下载

到 [Releases](../../releases) 页下载最新的 `NetChat_vX.X.zip`。

## 更新

模组自带更新分发：如果模组无法正常使用，请寻找**新手QAQ**更新模组（QQ群 **1137052535**；和作者在同一个服务器里会自动传给你）。

## 编译

`src/` 下是完整源码，`dotnet build` 即可（需要引用 Terraria.exe、tContentPatch.dll 等本地文件，路径在 csproj 里按需调整）。

## 协议安全说明

更新分发采用 RSA-2048 签名：私钥只在作者机器上，客户端内置公钥验签，没有私钥无法伪造更新包。
